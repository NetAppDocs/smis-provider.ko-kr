= 런타임 라이브러리 문제
:allow-uri-read: 
:icons: font
:imagesdir: ./media/
:pp: &#43;&#43;


[role="lead"]
NetApp SMI-S Provider는 Windows 환경에서 런타임 라이브러리 문제를 일으킬 수 있습니다. 필요한 Microsoft Visual C{pp} 재배포 가능 패키지를 설치하여 이 문제를 해결하십시오.

* * 문제 *
+
런타임 라이브러리 문제가 발생합니다.

* * 시정 조치 *
+
www.microsoft.com 에서 Microsoft Visual C{pp} 2010 재배포 가능 패키지(x86)를 설치합니다.
